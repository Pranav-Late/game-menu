# Game & Utility Menu (Python)

A menu-driven Python program that lets you run multiple small games and utilities from a single place.

This project is part of my project-based learning journey in programming.  
Each option in the menu launches a separate program stored in the repository.

---

## Features

Currently included programs:

- 🎮 Tic Tac Toe (C, compiled `.exe`)
- 🎯 Guess The Number (Python)
- 🧩 Sudoku (Python)
- 🔢 Number Base Converter (Binary / Decimal / Octal / Hexadecimal)
- 🧮 Calculator (Basic arithmetic)

## How to Run

1. Clone the repository:
    ```bash
    git clone <repo-url>
2. Navigate into the project folder:
    cd game-menu
3. Run the menu:
    python game_menu.py

Note:

- Python must be installed and added to PATH
- Tic Tac Toe is a Windows .exe file
